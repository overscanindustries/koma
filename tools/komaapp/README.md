# Koma app

The Koma app is the browser interface for setup, camera settings, looks, photos, shooting and webcam.

From this directory, install dependencies and start the development server:

```sh
npm ci && npm run dev
```

Run `koma` or the [bridge](../komaset/bridge/README.md) alongside it.
`npm run build` writes `dist/`, which is committed so installs do not need Node.
See [screens and flows](FLOWS.md).
