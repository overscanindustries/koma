# Koma identity

The logo is コマ ("koma", one frame of film) beside the word KOMA, outlined from `KomaWordmark.ttf`. マ alone is the favicon, tray and app icon. The README header uses `koma-logo-light.svg` and `koma-logo-dark.svg` by color scheme.

The geometry comes from `tools/komalauncher/komamark.py`. `tools/komalauncher/make_assets.py` regenerates the icons; the two lockups are written from the same module and the wordmark font.
