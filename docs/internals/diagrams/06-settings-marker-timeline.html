Settings block and the U marker migration

Each marker group is initialised once: if its marker byte is not U (0x55), 2.40 writes the group defaults. The dating comes from each held version writing its own default block and 2.40 booting on it.

Sources: internals chapter 05 (marker groups); analysis/emu-update-replay/README.md section 2 (marker dating, written bytes). Evidence class: EMU on default blocks; real user settings were not read. 2.20, 2.21 and 2.30 images are not held.
