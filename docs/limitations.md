# Limitations

- Koma supports the original GR DIGITAL with Ricoh firmware 2.40. Setup needs an SD card of 2 GB or less. Larger cards must be FAT32 with clusters of 32 KB or less; exFAT is not supported. Only 64 GB cards have been tested on a camera. Install Koma in the camera to use larger cards.
- KOMA is unavailable in movie mode. The IMG SET icon shows the underlying stock setting. The stock ADJ detail page edits stock values that a look ignores.
- The live-view preview omits the tone curve, warmth, grain, vignette and SELECT's retained colour.
- The app prevents photo reads while Remote is active because card reads interrupt live view. A quick-press tether shot failed to save once. Settings changes can report busy after an EV change.
- An ADJ freeze occurred on earlier builds and also on stock firmware on one camera. The Koma fix has not been tested on a camera.
- Recovery from a flash that does not boot has not been demonstrated. Restoring stock over the current Koma firmware and removing Koma from internal memory have not been tested on a camera.

See the [status table](user-guide.md#status) for camera test coverage.
