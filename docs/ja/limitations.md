# 制限事項

- Komaが対応するのは、リコーのファームウェア2.40を載せた初代GR DIGITALです。セットアップには2GB以下のSDカードが必要です。2GBを超えるカードは、クラスターサイズ32KB以下のFAT32でフォーマットされている必要があります。exFATには対応していません。カメラで試したのは64GBのカードだけです。大容量カードを使うには、Komaをカメラ本体にインストールしてください。
- 動画モードではKOMAを使えません。IMG SETのアイコンは、内部で使われる純正の設定を表示します。純正のADJ詳細ページで編集するのは純正の値で、ルックはその値を無視します。
- ライブビューのプレビューには、トーンカーブ、暖かさ、粒状感、周辺減光、SELECTで残す色が反映されません。
- Remote使用中は、アプリが写真の読み出しを止めます。カードを読むとライブビューが途切れるためです。クイックプレスのテザー撮影で、1回だけ保存に失敗したことがあります。露出補正を変えた直後は、設定変更がbusyを返すことがあります。
- 以前のビルドでADJのフリーズが起きました。1台のカメラでは純正ファームウェアでも起きています。Komaの修正はカメラでまだ試していません。
- 起動しなくなった書き込みからの復旧は、まだ実証されていません。現在のKomaファームウェアの上から純正を書き戻すことと、内蔵メモリーからKomaを削除することは、カメラで試していません。

カメラでのテスト範囲は[テスト状況の表](user-guide.md#テスト状況)を参照してください。
