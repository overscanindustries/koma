# 変更履歴

## [1.0.0]

### 追加

- カメラのメニューにKOMAタブを追加。メニュー構成は5タブ、純正＋KOMA、GR IIの3種類。
- 1m〜無限遠のスナップフォーカス距離と、フルプレススナップ。
- オートISOの上限と、シャッター速度の低速限界。
- 白とび警告とフォーカスピーキング。
- 最長240秒の長時間露光。
- IMG SETに21種類のルック：モノクロ10種、カラー6種、STANDARD、SELECT、カスタム枠3つ。
- ルックごとの編集：トーンカーブ、コントラスト、キー、シャドウ、ハイライト、フィルター、調色、彩度、暖かさ、ティント、シャープネス、粒状感、周辺減光。
- ADJレバーへのルック割り当てと、液晶モニターでのルックのプレビュー。
- FAT32のSDHC・SDXCカードに対応。
- バッテリーログ。
- Komaアプリ：セットアップ、ルック、カメラ設定、写真の取り込み、ライブビュー付きのテザー撮影、Webカメラ。
- 設定のバックアップ、復元、カメラ間のコピー。
- macOSではHomebrew、LinuxとWindowsではpipxでインストール。

### 修正

- バッテリーを抜いて日時が失われたあと、日付と時刻を復元するようにしました。
- 2回目のテザー撮影セッションが10〜20秒止まる問題を修正しました。
