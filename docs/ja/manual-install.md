# 手動インストール

アプリの案内に沿ったセットアップは[インストール](install.md)を参照してください。必要なものは、ファームウェア2.40のGR DIGITAL、リコーの2.40アップデートファイル（`qrflect3`または`gr-240.exe`。[リコー](https://www.ricoh-imaging.co.jp/english/r_dc/download/firmware/grd/win.html)から入手。ハッシュ値は[インストール](install.md#カメラへのkomaのインストール)に記載）、充電済みのバッテリー、カードリーダー、2GB以下のSDカード、[ビルド](building.md)に書いたツールです。復元用に、リコーのアップデートファイルを手を加えずに保管しておいてください。

## ファームウェアのビルドと書き込み

```sh
tools/koma/koma make-firmware /path/to/qrflect3 -o QRFLECT3
```

`gr-240.exe`を読むには`bsdtar`が必要です。

1. `QRFLECT3`を小容量カードのルートにコピーします。ほかのアップデートファイルは置きません。`QRFLECT7`は絶対にコピーしないでください。
2. モードダイヤルを動画にします。UPとTELEを押したまま、液晶モニターが点灯するまでPLAYを約3秒押し続けます。指を離して約5秒待ち、RIGHT、続いてMENU/OKを押します。
3. ランプが緑に点滅している間は、電源を切らないでください。
4. 再起動後も、サービス画面のバージョン表示は`02.40`のままです。新しく撮った写真のMakerNoteのファームウェアタグは`240K1.0`になります。`exiftool -n -FirmwareVersion R00nnnnn.JPG`で確認します。

## Komaのインストール

リコーのファイルからKoma 1.0のパッケージを作り直します（リリースには、リコー由来のバイトを含まない`dist-release/koma-1.0.0.grmod.delta`として収録しています）。

```sh
tools/koma/koma make-package /path/to/qrflect3 -o GRMOD.BIN
```

[ビルド](building.md)の手順で独自のパッケージを作ることもできます。2GB以下のSDカードなら、パッケージを`GRMOD.BIN`としてカードのルートにコピーし、電源を入れます。メニューにKOMAが現れます。大容量カードを使う場合は、内蔵メモリーにインストールします。

1. 小容量カードに、[インストーラー](../../analysis/sdhc/diag/README.md)（英語）を`GRMOD.BIN`として、パッケージを`KOMAPKG.BIN`として置きます。
2. 電源を入れて60秒待ち、電源を切ります。
3. カードの`IRODUMP.TXT`を読みます。成功していれば`result=installed`または`result=same`で、`dst_valid=1`、`copy_rc=0`、最終行が`end=1`です。`result=unmounted`や`badsrc`は何も書き込まれていないことを、`verify_fail`は不正なコピーが削除されたことを示します。
4. カードから`GRMOD.BIN`と`KOMAPKG.BIN`を削除します。カード上の`GRMOD.BIN`は、内蔵メモリーのものより優先されます。

## 更新・削除・復元

- カードにインストールした場合は、`GRMOD.BIN`を置き換えて更新します。内蔵メモリーの場合は、新しいパッケージでインストーラーの手順を繰り返します。そのあとカメラの電源を入れ直します。
- カードにインストールした場合は、`GRMOD.BIN`を削除するか、カードを抜けば削除できます。
- 内蔵メモリーのものを削除するには、小容量カードにインストーラーを`GRMOD.BIN`として置き、その横に空の`KOMARM.TXT`を置きます。`KOMAPKG.BIN`は置きません。60秒間起動させ、`result=removed`になっているか確認します。この削除手順はカメラで試していません。
- リコーのファームウェアに戻すには、手を加えていない`qrflect3`を`QRFLECT3`として、上の手順で書き込みます。現在のKomaファームウェアの上から復元することは、カメラで試していません。書き込み後も内蔵メモリーにコピーが残ることがあります。内蔵メモリーを空にしておく必要がある場合は、先に削除してください。

メニューが変わらない場合は、ファイル名、カードのルートに置いたか、ファームウェアタグを確認します。SDHC・SDXCカードでは内蔵メモリーへのインストールが必要です。カメラが固まったら、バッテリーとカードを抜きます。削除後もKomaの設定はカメラに残りますが、純正ファームウェアはそれを無視します。
